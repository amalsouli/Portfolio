# Amal Souli — Portfolio

Personal portfolio of **Amal Souli**, Software Engineer (mobile, full-stack web, .NET).

🔗 **Live:** https://amalsouli.github.io/Portfolio/

## Stack
React 18 · TypeScript · Vite · Tailwind CSS · Framer Motion · GitHub Pages (GitHub Actions)

## Features
- Bilingual EN / FR and light / dark theme
- Experience timeline, filterable project cards, skills, education and languages
- One-page CV (EN + FR) generated as PDF from the same data

## Develop
```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
npm run cv       # regenerate public/cv/*.pdf (needs Edge or Chrome)
```

All content lives in [`src/data/profile.ts`](src/data/profile.ts).
